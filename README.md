**NusaStat** — a national statistics site for Indonesia, built from static files with no network requests. Real figures from BPS, Bank Indonesia, and the World Bank: headline indicators, a population pyramid and growth series, GDP growth and sector shares, foreign trade, a searchable and sortable table of all 38 provinces, and a two-province comparison tool. Every chart is hand-drawn SVG; every figure carries its source and year.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or serve `app/` with any static file server.

To build the graded output (what the grader runs):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
